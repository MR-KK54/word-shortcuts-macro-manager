Word Connector Setup (VBA)

To connect Microsoft Word on your computer with this manager, import these VBA connector files into Word's VBA editor (Alt+F11). When importing macros into Word, existing modules with the same name are automatically replaced!

  1. Download the six .bas files below.
  2. In Microsoft Word, press Alt+F11 to open the VBA Editor, then click File → Import File for each module.
  3. Enable "Trust access to the VBA project object model" under Word File → Options → Trust Center → Trust Center Settings → Macro Settings.
  4. Press Alt+F8 and run ShowToolkitMenu anytime. Pick 7 - Direct Sync ALL From Server to install every macro and keyboard shortcut straight into Word from this server (no file dialogs).

🚀 Export Directly to MS Word

Choose which groups to install and click Install into Word Now — it pushes straight into the open Word on this PC via a registered wordtoolkit:// link (no downloads).

First time on this PC: download and run WordToolkit_Setup.vbs once (close Word first) — it imports the connector into Word and registers the wordtoolkit:// link. Afterwards this button installs directly, every time. Requires "Trust access to the VBA project object model" (File > Options > Trust Center > Macro Settings). Ribbon installs to %APPDATA%\Microsoft\Office\Word.officeUI — restart Word to apply.
